# ごはん台帳 — 立ち上げ手順

家族4人でつかう献立・在庫・買い物・食費のアプリです。
**上から順に、1つずつやれば動きます。** 途中で分からなくなったらそこで止めて聞いてください。

構成は次の3つだけです。

- **画面**（このフォルダの中身）… GitHub Pages に置く
- **データ**… Googleスプレッドシート
- **つなぎ**… Google Apps Script（GAS）

**このフォルダには、パスワードやURLなどの秘密情報は入っていません。** GitHubに公開しても大丈夫です。
GASのURLと家族の合言葉は、各自がスマホの設定画面で入れて、その端末の中にだけ残ります。

---

## A. スプレッドシートとGASを用意する（15分ほど）

1. Googleドライブで **新しいスプレッドシート**を作り、名前を「ごはん台帳」にする
2. メニューの **拡張機能 → Apps Script** を開く
3. 左の「エディタ」で、最初からある `コード.gs` を消して、**このフォルダの `gas/` の中の4つ**を同じ名前で作って貼り付ける
   - `Code.gs`
   - `Setup.gs`
   - `Domain.gs`
   - `BabyFoods.gs`（離乳食の103食材データ）
   （＋のボタン → スクリプト、でファイルを増やせます）
4. 左下の **⚙ プロジェクトの設定** を開き、**スクリプト プロパティ** に1つ追加する
   - プロパティ： `FAMILY_SECRET`
   - 値： **家族で決めた合言葉**（他人に推測されない文字列。あとでスマホに入れます）
   - ※ ここに入れた合言葉は、GitHubにもこのフォルダにも出ていきません
5. エディタに戻り、上の関数の選択で **`initSheets`** を選んで **実行**
   - 初回は権限の確認が出ます。「詳細」→「（安全ではないページ）に移動」→ 許可、で進みます
   - 「作成したシート：…」と出たら成功です。スプレッドシートにシートが並びます
   - **シートは全17枚**です。`baby_foods` `baby_legend` `baby_ng` の3枚が無いときは、
     `BabyFoods.gs` を貼り忘れています。貼ってから `initSheets` をもう一度実行してください
     （既にあるシートには触らないので、何度実行しても中身は壊れません）

---

## B. GASを公開する（5分）

1. Apps Script の右上 **デプロイ → 新しいデプロイ**
2. 歯車 → **ウェブアプリ** を選ぶ
3. 設定を次のようにする
   - 説明：なんでも可（例：v1）
   - **次のユーザーとして実行： 自分**
   - **アクセスできるユーザー： 全員**
     - ⚠️ 「**Googleアカウントを持つ全員**」ではありません。それを選ぶと、アプリからの通信が
       Googleのログイン画面に飛ばされて動きません。必ず「**全員**」を選んでください
4. **デプロイ** を押し、出てきた **ウェブアプリのURL**（`https://script.google.com/macros/s/.../exec`）をコピーしておく

> 「全員」にするのは、家族3人のスマホから使うためです。
> URLを知られただけでは中身は見られません。毎回サーバー側で合言葉を確かめ、違えば断ります。

**コードを直したときは、毎回「デプロイ → デプロイを管理 → 鉛筆 → バージョン：新バージョン → デプロイ」が必要です。** これを忘れると変更が反映されません。

## C. 画面をGitHubに置く（初めてなら、コマンドは使わない方法で）

1. https://github.com でアカウントを作る
2. 右上の **＋ → New repository**（翻訳時は「新しいリポジトリ」）
   - Repository name： `gohan-app`
   - **Public** のまま（無料でPagesを使うため。秘密情報は入っていないので大丈夫です）
   - **Create repository**
3. 次の画面の青い枠の中にある **uploading an existing file** を押す
   - Chromeの自動翻訳が効いていると **「既存のファイルをアップロードして」** と表示されます
4. Finderでこのフォルダを開き、**中身**（`gohan-app` フォルダ自体ではなく、`index.html` などの中身）をまとめてドラッグ＆ドロップする
   - `index.html` / `app.js` / `styles.css` / `manifest.json` / `sw.js` / `icons` フォルダ / `README.md`
   - `gas` フォルダも一緒に上げて構いません（コードの控えとして残ります）
5. 下の **Commit changes**（翻訳時は「変更をコミットする」）を押す
6. 上の **Settings → Pages**（翻訳時は「設定 → ページ」）を開く
   - Source（ソース）： **Deploy from a branch**（ブランチからデプロイ）
   - Branch（ブランチ）： **main** ／ **/ (root)** → **Save**（保存）
7. 1〜2分待つと、同じ画面にURLが出ます
   → このリポジトリの場合は **https://pipper-sakura.github.io/gohan-app/**

> 英語のラベルが見つからないときは、Chromeの自動翻訳が効いています。
> アドレスバー右の翻訳アイコンから「英語のまま表示」にすると、この手順書と同じ表示になります。

> 慣れてきたらMacから `git` で更新できるようにします。そのときは
> **`git commit` はiMac側で行ってください**（デスクトップは2台のMacでiCloud同期されるため、
> 両方から同時にコミットすると `.git` が壊れることがあります）。

## D. スマホに入れる（家族それぞれ）

1. iPhoneのSafariで **https://pipper-sakura.github.io/gohan-app/** を開く
2. 共有ボタン → **ホーム画面に追加**
3. アプリを開くと設定画面が出るので、次の2つを入れて「保存してつなぐ」
   - **GASのウェブアプリURL**（Bの4でコピーしたもの）
   - **家族の合言葉**（Aの4で決めたもの）
     - ひらがなでも動きますが、スマホで毎回入れるので、日本語入力の切り替えや予測変換で
       間違えやすいです。**ローマ字＋数字で12文字以上**が入力しやすくておすすめです
4. 右上のボタンから **自分が誰か** を選ぶ
5. 設定タブの **家族の設定** で、呼び名と、赤ちゃんの誕生日（`2026-04-21`）を入れる
6. 設定タブの **苦手な食材** で、自分の分に ○ / △ / × を付ける
   - △ は「少量なら食べられる」
   - 調理法で変わるものは「メモ」に書いておくと、あとで提案に効きます

## E. 最初の1週間の使い方

1. **計画タブ**で今週の献立を入れる（昼は平日だけ、朝と夜は毎日）
2. **「献立を確定して在庫に反映」** を押す
   - 肉・魚・卵・豆腐などの主役の食材が「予定あり」になります
   - 野菜や常備品は「どうぞ」のまま残ります（少し使っても計画は崩れないため）
3. **「買い物リストを作る」** を押す
   - 「食材／昼で使うメニュー／夜で使うメニュー」の3列で、八百屋 → スーパー → コープの順に並びます
4. 週末に昼5食を作ったら、計画タブの **「作ったので在庫に入れる」**
   - 月・火はパーシャル、水〜金は冷凍に自動で振り分けます
   - 冷凍にした分は、食べる前日の夜に「今日やること」へ移動リマインドが出ます
5. **今日タブ**が普段の入口です。自分を選ぶと「どうぞ」に、遠慮なく食べていいものだけが出ます

**気になったことは、どの画面からでも右下の「ひとこと」から送ってください。**
スクリーンショットも付けられます。届いた内容は設定タブの「みんなの声」に並びます。

## F. 困ったとき

| 症状 | 見るところ |
| --- | --- |
| 「合言葉が違います」 | スクリプトプロパティの `FAMILY_SECRET` と、スマホに入れた合言葉が一致しているか |
| 「FAMILY_SECRET が設定されていません」 | Aの4をやり直す |
| 直したのに変わらない | Bの最後。**デプロイし直し**が必要です |
| 「シートがありません」 | Aの5の `initSheets` を実行する |
| 離乳食タブが空 | `BabyFoods.gs` を貼って `initSheets` を実行し直す |
| ログイン画面に飛ばされる | Bの3。「Googleアカウントを持つ全員」ではなく「全員」にする |
| つながらない | 前回の内容が表示されます。電波が戻れば自動で最新になります |
